# NULL Pouches WooCommerce theme

Custom WordPress classic theme for WooCommerce, initial working storefront scaffold. Includes home, product catalogue, product details, cart and checkout via WooCommerce. Uses existing externally hosted NULL product images and brand colors.

## Installation
1. GitHub Code > Download ZIP (or use GitHub Actions to package theme).
2. WordPress > Appearance > Themes > Add new > Upload theme.
3. Install and activate WooCommerce. Complete its setup for cart, checkout, payments, shipping and products.
4. Create real products with slugs focus, energy, sleep, configure currency and taxes.
5. Visit homepage, shop, product, cart, checkout to validate.

**Status**: Initial conversion, **not pixel-identical** to original 150 KB prelaunch site. Legal text, multi-language sales, shipping, payment methods, inventory and real end-to-end purchase flow need staging QA before publication. Original site repository has not been modified. External Shopify CDN images must eventually be moved to WordPress media.
